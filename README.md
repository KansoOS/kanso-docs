# KansoOS Documentation

KansoOS is a mobile environment designed to simplify and secure smartphone usage for neuroatypical users.

This repository is the central documentation hub for the project. It contains product scope, architecture decisions, security notes, MVP definition, and operational guidelines.

## Current Direction

KansoOS starts as an Android Enterprise managed experience, not as a full custom Android fork.

The first product target is:

- a cognitive-accessibility Android launcher;
- a local policy layer on the device;
- a caregiver dashboard;
- remote configuration and auditability;
- compatibility with certified Android devices and sensitive apps.

An AOSP-based edition remains a longer-term research and integration track.
